A modern, feature-complete Progressive Web App starter kit built with the latest web technologies and best practices. Achieve perfect Lighthouse PWA scores out of the box with advanced caching strategies, offline support, and modern web APIs.

## 🚀 Quick Start

### Prerequisites
- Node.js 18+ and npm 9+
- Modern browser with PWA support

### Installation
```bash
git clone https://github.com/your-username/pwa-kit-modern.git
cd pwa-kit-modern
npm install
```

### Development
```bash
# Start development server with HTTPS
npm run dev

# Run tests
npm test

# Run E2E tests
npm run e2e

# Build for production
npm run build

# Preview production build
npm run preview
```

### SSL Certificate Setup
For full PWA features in development, generate SSL certificates:
```bash
# Create cert directory
mkdir cert

# Generate self-signed certificate (macOS/Linux)
openssl req -x509 -newkey rsa:4096 -keyout cert/key.pem -out cert/cert.pem -sha256 -days 365 -nodes

# Windows (using mkcert - install first: https://github.com/FiloSottile/mkcert)
mkcert -key-file cert/key.pem -cert-file cert/cert.pem localhost 127.0.0.1
```

## 🔧 Configuration

### PWA Manifest
Update `public/manifest.webmanifest` with your app details:
```json
{
  "name": "Your App Name",
  "short_name": "YourApp",
  "start_url": "/",
  "display": "standalone",
  "theme_color": "#1976d2",
  "background_color": "#ffffff"
}
```

### Service Worker
The service worker is automatically generated by Workbox. Customize caching strategies in `vite.config.js`:
```javascript
VitePWA({
  workbox: {
    runtimeCaching: [
      // Add your custom caching rules
    ]
  }
})
```

### Icons & Assets
The starter includes minimal placeholder icons. **You should generate your own branded icons** for production:

**Current Icons (replace with your own):**
- `favicon-32.png` - Browser favicon
- `apple-touch-icon.png` - iOS home screen icon  
- `img/icons-192.png` - Android home screen icon
- `img/icons-512.png` - PWA splash screen icon

**Recommended Icon Generation Tools:**
- [PWA Builder](https://www.pwabuilder.com/) - Complete PWA asset generation
- [RealFaviconGenerator](https://realfavicongenerator.net/) - Cross-platform favicon generator
- [App Icon Generator](https://appicon.co/) - Generate all sizes from one image

**Full Icon Set Needed for Production:**
