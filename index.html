Overview

This modernized PWA starter provides everything needed to build production-ready Progressive Web Apps with perfect Lighthouse scores, advanced caching, offline support, and modern web APIs.

Quick Start

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production  
npm run build

Requirements

  • ✅ HTTPS - Required for PWA features
  • ✅ Modern Browser - Service Worker support
  • ✅ Node.js 18+ - For development tools

Modern Architecture

🌐 Advanced Connectivity

Multi-endpoint testing with Network Information API integration for real-time connection quality monitoring. Gracefully handles offline scenarios with intelligent caching strategies.

⚡ Enhanced Service Worker

Workbox-powered caching with Background Sync, Push Notifications, and automatic updates. Implements cache-first, network-first, and stale-while-revalidate patterns.

🔧 Development Tools

Vite for lightning-fast builds, TypeScript for type safety, Vitest for unit testing, and Playwright for cross-browser E2E testing.
